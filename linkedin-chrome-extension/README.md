# Xonier CRM LinkedIn Connector (Chrome Extension)

Allows non-technical Xonier CRM users to connect their LinkedIn account in **1 click** using their existing Chrome session — no DevTools / Inspect / manual cookie copying required.

## Install Locally in Chrome (Developer Mode)
1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode** (top-right toggle).
3. Click **Load unpacked** and select this `linkedin-chrome-extension` folder (or unzip `xonier-linkedin-connector.zip`).
4. Reload Xonier CRM `/linkedin` and click **1-Click Auto-Connect from Chrome**.

## Production Distribution
Zip this folder (or publish it to the Chrome Web Store as an unlisted/public extension) so any client can install it in 1 click.
